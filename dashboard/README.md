# OxyTrack dashboard MVP

## Objective

Provide real-time visibility into hospital oxygen infrastructure.

## Dashboard components

### Live pressure card

Current pressure

Pressure trend

Pressure status

### Live flow card

Current flow rate

Consumption trend

Flow status

### Zone overview

ICU

Theatre

Emergency

Neonatal

General Ward

### Alerts

Pressure drop

Leak detected

Sensor offline

Communication failure

### Analytics

24-hour pressure trend

24-hour flow trend

Consumption forecast

Infrastructure health score

## Technology stack

* Next.js
* React
* Tailwind CSS
* Recharts
* MQTT WebSocket
* PostgreSQL
