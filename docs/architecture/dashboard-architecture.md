# OxyTrack dashboard architecture

## Objective

Design a centralized monitoring dashboard for biomedical engineers and hospital administrators.

## Primary users

Biomedical engineers

Clinical engineering departments

Hospital administrators

Maintenance teams

Emergency response coordinators

## Dashboard modules

### System overview

* hospital map
* oxygen network status
* active alerts
* infrastructure health score

### Pressure monitoring

* live pressure gauges
* zone pressure map
* pressure trend charts
* pressure differential analysis

### Flow monitoring

* ward-level flow rates
* department consumption
* peak demand analysis
* historical flow trends

### Alert center

* pressure drops
* leak warnings
* sensor failures
* communication failures
* critical infrastructure events

### Analytics

* oxygen consumption trends
* zone utilization
* infrastructure performance
* maintenance recommendations
* predictive risk indicators

## User roles

### Biomedical engineer

* full system access
* sensor diagnostics
* maintenance tools
* calibration records

### Hospital administrator

* operational dashboard
* consumption reports
* cost analytics
* infrastructure summaries

### Maintenance technician

* work orders
* fault locations
* repair history
* equipment status
