# Flow rate monitoring research

## Purpose

Flow rate monitoring provides visibility into oxygen consumption behaviour across hospital departments.

## Key applications

* ward-level oxygen consumption
* abnormal flow detection
* leak identification
* peak demand analysis
* oxygen forecasting

## OxyTrack approach

Flow sensors will measure oxygen consumption across selected pipeline zones and transmit data for real-time visualisation, trend analysis, and predictive demand forecasting.

## Expected benefits

* reduced oxygen wastage
* improved refill planning
* faster anomaly detection
* evidence-based resource allocation
