# OxyTrack product roadmap

## Vision

Build Africa’s leading intelligent oxygen infrastructure monitoring platform for hospitals through IoT telemetry, analytics, and predictive maintenance.

## Phase 1 — Research and architecture (August–September 2026)

### Objectives

* validate hospital oxygen workflows
* define system architecture
* evaluate sensor technologies
* design telemetry pipeline
* develop dashboard concepts

### Deliverables

* architecture documentation
* telemetry documentation
* research repository
* initial schematics
* dashboard wireframes

## Phase 2 — Prototype development (October–November 2026)

### Hardware

* ESP32 telemetry node
* pressure sensor integration
* flow sensor integration
* local data buffering
* calibration system

### Software

* MQTT communication
* cloud ingestion
* database
* dashboard prototype
* alert engine

## Phase 3 — Pilot deployment (December 2026–January 2027)

### Pilot objectives

* validate sensor accuracy
* test communication reliability
* evaluate dashboard usability
* measure oxygen visibility improvements
* collect biomedical engineering feedback

## Phase 4 — Platform intelligence (February–April 2027)

### Advanced features

* predictive maintenance
* leak detection analytics
* consumption forecasting
* infrastructure health scoring
* automated reporting

## Phase 5 — Commercial deployment (May 2027 onward)

### Target customers

* Level 6 hospitals
* Level 5 hospitals
* Level 4 hospitals
* private hospital networks

## Long-term vision

Create a national oxygen telemetry platform that enables continuous monitoring, analytics, and optimization of hospital oxygen infrastructure across Kenya and Africa.
