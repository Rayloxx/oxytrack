# OxyTrack pilot implementation plan

## Pilot objective

Demonstrate real-time monitoring of hospital oxygen pressure and flow across selected pipeline zones.

## Pilot scope

### Monitoring zones

* oxygen source
* manifold room
* ICU
* operating theatre
* emergency department
* neonatal unit

## Hardware deployment

### Sensors

* pressure sensors
* flow sensors
* temperature sensors

### Telemetry

* ESP32 sensor nodes
* Wi-Fi connectivity
* MQTT communication

## Dashboard deployment

### Features

* live pressure monitoring
* live flow monitoring
* zone status
* alert notifications
* historical trends
* infrastructure health

## Evaluation metrics

### Technical

* sensor accuracy
* communication uptime
* data latency
* alert response time
* dashboard reliability

### Operational

* leak detection effectiveness
* pressure anomaly detection
* oxygen visibility improvement
* maintenance efficiency
* biomedical engineer satisfaction

## Pilot timeline

### Week 1

Site assessment

### Week 2

Sensor installation

### Week 3

Telemetry validation

### Week 4

Dashboard testing

### Week 5

Operational monitoring

### Week 6

Evaluation and reporting

## Expected outcomes

* validated telemetry architecture
* verified sensor performance
* functional monitoring dashboard
* documented pilot results
* deployment readiness assessment

## Long-term objective

Establish a scalable oxygen infrastructure intelligence platform capable of deployment across multiple hospitals and county health systems.
