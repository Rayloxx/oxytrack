# OxyTrack design system

## Design philosophy

OxyTrack is not a healthcare website.

It is a medical infrastructure intelligence platform.

The interface should communicate:

* precision
* reliability
* engineering excellence
* real-time intelligence
* operational confidence

## Core design principles

### Functional beauty

Every visual element must communicate system state.

### Motion with meaning

Animations should represent oxygen movement, telemetry transmission, pressure propagation, or infrastructure activity.

### Information hierarchy

Critical telemetry is always visually dominant.

### Calm confidence

Avoid aggressive marketing visuals.

The interface should feel like mission-critical software.
