# OxyTrack animation engine

## Objective

Create a physically inspired animation system that represents oxygen flow, pressure propagation, telemetry communication, and infrastructure intelligence.

Animations are functional visualizations of system behavior.

## Motion principles

### Pressure is energy

Pressure creates expanding wave motion.

### Flow is direction

Flow creates particle movement.

### Telemetry is communication

Telemetry creates synchronized pulses.

### Infrastructure is stability

Stable systems move calmly.

Anomalies create controlled disruption.

## Oxygen particle engine

### Behavior

Particles move through pipeline splines.

Velocity responds to flow rate.

Density responds to oxygen consumption.

Brightness responds to pressure.

### Flow equation

Velocity = Base Speed × Flow Multiplier

Pressure affects particle compression.

Flow affects particle spacing.
