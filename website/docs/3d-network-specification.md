# OxyTrack 3D oxygen network specification

## Vision

Create a cinematic, physically believable oxygen infrastructure visualization that serves as the primary brand signature of OxyTrack Technologies.

The network represents a living hospital oxygen distribution system.

## Scene composition

### Central oxygen tank

Positioned slightly left of center.

Large cylindrical form.

Brushed metallic material.

Soft cyan internal glow.

### Main manifold

Located at the center.

Acts as the network hub.

Multiple pipeline branches emerge from the manifold.

### Clinical zones

ICU

Operating Theatre

Emergency

Neonatal

HDU

General Ward

Each zone is represented by a sensor cluster.

## Pipeline geometry

Pipelines are semi-transparent tubes.

Material properties:

glass-like transmission

soft cyan emission

subtle metallic reflections

rounded junctions

Pressure waves travel through the pipelines continuously.

## Sensor nodes

Sensor nodes are circular intelligent devices.

States:

idle

monitoring

warning

critical

communication

Idle:

soft cyan breathing glow.

Monitoring:

periodic pulse.

Warning:

amber pulse.

Critical:

red oscillation.

Communication:

wave propagation between connected nodes.

## Oxygen particle system

Particles represent oxygen movement.

Characteristics:

small

soft glow

variable velocity

flow direction

pipeline adherence

Particle density increases with flow rate.

Particle velocity changes with telemetry values.

## Pressure wave system

Pressure is visualized as expanding energy waves.

Wave properties:

cyan core

transparent edges

additive blending

smooth propagation

Pressure drops reduce wave intensity.

Pressure surges increase amplitude.

## Telemetry overlay

Floating holographic panels display live data.

Pressure

Flow rate

Temperature

Health score

Signal strength

Last update

Panels appear only when interacting with a node.

## Camera system

Default camera:

slow orbital movement

subtle vertical drift

cinematic depth

Mouse interaction:

parallax

slight rotation

depth response

Click interaction:

camera focuses on selected zone

smooth interpolation

maintains context

## Lighting

Primary light:

cool cyan directional light.

Secondary light:

soft white ambient light.

Accent lighting:

sensor node emission

## Animation system

### Network activation

Nodes activate sequentially.

Pipelines illuminate progressively.

Particles begin flowing.

Pressure waves initialize.

### Live monitoring

Continuous oxygen flow.

Sensor breathing.

Telemetry updates.

Micro camera motion.

### Alert state

Affected zone flashes.

Pipeline intensity changes.

Alert panel expands.

Camera subtly focuses on anomaly.

### Recovery state

Pressure stabilizes.

Flow normalizes.

Health score increases.

Network returns to monitoring mode.

## Brand objective

The oxygen network should become instantly recognizable.

When users see glowing pipelines, synchronized sensor nodes, and flowing cyan particles, they should immediately associate the experience with OxyTrack Technologies.
