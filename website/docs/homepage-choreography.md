# OxyTrack homepage choreography

## Objective

Guide the visitor through the journey of oxygen as it moves from storage to patient care, while simultaneously demonstrating the intelligence of the OxyTrack platform.

## Scene 1 — activation

Duration: 5 seconds

The screen is initially dark.

The OxyTrack logo appears.

A cyan pressure pulse expands outward.

The hospital oxygen network begins activating.

Telemetry values start streaming.

## Scene 2 — visibility

The headline fades in.

The network rotates slowly.

Sensor nodes pulse.

Pipelines illuminate.

Live pressure and flow values appear.

## Scene 3 — monitoring

The dashboard emerges.

Pressure gauges animate.

Flow charts populate.

Infrastructure health reaches 97%.

## Scene 4 — intelligence

A pressure anomaly appears.

The analytics engine highlights the affected zone.

Leak probability is calculated.

An alert is generated.

## Scene 5 — action

A biomedical engineer receives a notification.

The affected zone is isolated.

System health stabilizes.

The network returns to normal.

## Scroll progression

The scroll should feel like following a pressure wave through the hospital oxygen infrastructure.

Every section transition is synchronized with pipeline animation and telemetry updates.
