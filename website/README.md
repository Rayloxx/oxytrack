# OxyTrack website design specification

## Vision

Create a world-class digital experience that positions OxyTrack Technologies as the intelligence layer for hospital oxygen infrastructure.

The website should communicate engineering precision, medical reliability, and advanced infrastructure analytics.

## Design philosophy

The website is not a hospital equipment catalogue.

It is a medical infrastructure operating system.

Every interaction should feel:

* precise
* intelligent
* calm
* technical
* trustworthy

## Motion language

Animations should represent oxygen telemetry.

### Oxygen flow

Particles moving through pipeline networks.

### Pressure propagation

Expanding pulse rings.

### Sensor communication

Glowing node synchronization.

### Infrastructure intelligence

Network activation sequences.

Motion should be smooth, physics-inspired, and subtle.

## Interaction principles

Hover should reveal information.

Scroll should advance the story.

Animation should explain the technology.

No decorative motion.

Every animation must have engineering meaning.
