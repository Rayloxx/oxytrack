# Contributing to OxyTrack

## Engineering standards

All contributions should follow engineering-grade documentation and version control practices.

## Commit message format

Use conventional commits.

Examples:

* feat: add telemetry dashboard
* docs: update pressure monitoring research
* refactor: improve sensor architecture
* fix: correct MQTT topic structure

## Documentation

Technical decisions should be documented in the `docs/` directory.

## Branch strategy

* `main` – stable branch
* `feature/*` – new features
* `research/*` – research documentation
* `hardware/*` – embedded development

## Code quality

* modular architecture
* meaningful commit history
* documented technical decisions
* reproducible development process

## Mission

Every contribution should improve OxyTrack’s ability to provide real-time intelligence for hospital oxygen infrastructure.
